## Mathematical notation

### State-space form

A generic dynamic-system notation can be written as

$$
\frac{d\mathbf{x}}{dt}=\mathbf{S}\,\mathbf{r}\!\left(\mathbf{x},\mathbf{u},\boldsymbol{\theta}\right),
\qquad
\mathbf{y}=\mathbf{h}\!\left(\mathbf{x}\right).
$$

The symbols are intentionally generic: the equation checks spacing, subscripts, bold vectors, parameters, and display overflow without claiming that it represents a particular treatment process.

## Computational example

The following code is deliberately small and deterministic. It demonstrates Python syntax highlighting and a filename label.

```python file=state_model.py
from collections.abc import Callable

import numpy as np


def evaluate_rhs(
    state: np.ndarray,
    rates: Callable[[np.ndarray], np.ndarray],
    stoichiometry: np.ndarray,
) -> np.ndarray:
    """Return a generic right-hand side for layout verification."""
    # 中文注释用于验证系统 CJK 等宽回退
    return stoichiometry @ rates(state)


state = np.array([1.0, 0.5, 0.2])
very_long_identifier_for_horizontal_overflow_verification = evaluate_rhs(state, lambda values: values**2, np.eye(3))
```

## Long-form reading test

This paragraph is intentionally long enough to exercise the target reading measure, line height, and paragraph rhythm across several viewports. A technical note often has to carry definitions, assumptions, notation, caveats, and interpretation in the same narrative sequence, so the layout must remain calm even when the prose is dense. The design therefore relies on a stable text column, restrained contrast, generous vertical spacing, and clear heading transitions rather than decorative cards or oversized interface elements. This text makes no claim about a model, dataset, experiment, or treatment plant; it exists only to test reading comfort and wrapping behaviour on desktop, tablet, and mobile screens.[^layout]
