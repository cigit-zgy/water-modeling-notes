# One-sentence contribution

Paper2Agent把论文及其代码、数据和示例转成经参照输出检查的模型上下文协议（MCP）服务，使对话智能体能够复用科学工作流；证据主要支持特定任务中的执行复现与效率改善，而非通用的自主科学判断。

# Research question

科学方法从论文进入新研究通常需要人工找到仓库、处理依赖、理解输入输出并组合步骤。本研究问：这部分适配和使用工作能否被自动化为可调用、可检查、可组合的论文级接口？C01对应接口结构，C02/C03对应执行比较，C04/C06对应跨论文假说生成。三个问题层次不同，不能以问答准确率代替科学结论的可靠性。

# Scientific motivation

原文将工作置于可执行论文、代码关联、容器化环境和论文到代码系统之后。本文未独立系统检索这些领域的全部先例，因而不裁定“首次”或“范式已成立”。可核实的动机是：代码公开并不消除部署、参数语义和流程顺序负担。面向智能体的工具、资源和提示接口试图减少这些负担。其可执行工具层依赖实际代码与数据，不能简化为只读一份PDF就恢复完整方法；没有可执行工具时，资源层仍可支持文献综合。

# Method architecture

C01 / Figure 1区分构建端和使用端。构建端由Claude Code中的协调者组织环境管理、教程扫描、教程执行、工具提取和测试改进等角色；论文Methods将流程归为六步：定位仓库、建立隔离环境、发现教程、执行审计、提取并测试函数、组装MCP服务。工具封装可复用计算；资源保存文稿、代码和数据入口；提示定义有先后依赖的分析路径。使用端将服务接入对话智能体，按问题组合调用。

C10说明验证并非形式证明：Methods给出浮点值3%容差、感知哈希汉明距离小于20的图像检查、每函数最多六轮尝试（包含执行、诊断与修正）；失败函数取消工具装饰器，不进入最终服务。这些检查约束的是与教程参照输出的一致性。源代码自身的科学假设、单位或数据偏差不由输出相似性自动消除。工具固定后可以降低反复生成代码的变化，但仍需要维护依赖、模型API和输入契约。

# Data and experimental design

AlphaGenome教程和新查询各15个，每种方法独立运行5次；Figure 2b误差条为均值的标准误。Figure 2c每组75个运行来自15个查询乘5次，不能解释为75个独立问题。另有30个开放题的正文结果，主要基于实体匹配等预定义评分标准；两名专家独立评分，一致率96.7%，但并未对系统身份正式盲法。比较对象为Paper2Agent、Claude Code直接访问仓库、Biomni；系统提示和可访问信息不同，应按这些条件解释差异。

Scanpy正文报告4个主要数据集及7个扩展数据集，Reporting Summary明确写11个数据集各执行一次；Methods又表述3个PBMC及4个其他数据集。这里记录表述不一致，不自行推定三处清单如何对应。Figure 3仅提供代表性流程和配对图像；未获得外置补充表，不能对全部数据集的参数自适应表现做逐项确认。

C09：100篇计算生物学论文按bioRxiv生物信息学类别从2025年12月向前回溯抽样；74篇完成工具提取、执行和自动验证。其300个教程问题的准确率是在成功子集上评估。26篇数据/发现论文用于100个跨文本与补充信息综合问题，10篇非生物计算论文用于42个执行问题。这些语料、抽样、评价定义见主文/Methods；补充说明、完整提示与逐例结果未提供，本文只转述主文汇总，不声称重现此基准。

GPR137案例复用已有顺式调控元件（CRE）干预数据和CD4+ T细胞基因敲低数据，比较三种培养状态。Figure 4每点为一个下游基因，n=20/21/19，不是受试者数量。原文没有开展这项位点解释的新湿实验。人类从智能体提出的十项策略中选择特征相关分析，因此应称为有人类参与的证据整合。

# Main findings

C02：AlphaGenome教程/新查询准确率分别98.7±1.3%和100.0±0.0%；直接仓库基线为82.7±3.4%和78.7±4.4%；Biomni为37.3±4.0%和56.0±3.4%。开放题则为82.7±2.4%、56.7±2.3%、72.2±2.2%。教程查询中位运行时相对两个基线缩短至约1/1.9和1/3.1；新查询约1/2.9和1/3.8。这是查询阶段，不包括前置服务构建成本。正文报告AlphaGenome构建22工具约45分钟、14美元，Scanpy生成7工具约45分钟、13美元；属于文中条件下的历史API费用，不能当作当前报价或通用成本。

C03：在相同数据与匹配参数条件下，Scanpy输出的细胞/基因计数及标记结果据正文与人工执行相符；源图c展示配对图形。这支持工作流复现，不支持“比人工更正确”的聚类结论。C05：TISSUE区间宽度示例扩展了方法类型，但图像对照本身没有估计实际覆盖率。

C09：74/100篇成功转换；599个候选工具中593个通过自动验证。成功论文上的300题准确率91.2±1.6%，直接仓库Sonnet 4和Sonnet 4.6基线分别80.3±2.3%和86.3±1.1%。应同时报告转换失败边界，不能只呈现成功工具条件下的问答率。其他语料主文汇总为非生物42题98.1±0.8%、资源层100题89.0±3.1%；未用缺失补充信息对这些汇总做独立复算。

# Claimed innovations

## Innovation 1

- Author claim: 将论文转化为可交互、可执行的智能体原生研究对象。
- Prior approach / comparison target: 原文对比可执行论文、代码/容器平台、论文到代码以及仅文本检索；本review未穷尽先前工作，不能确认首创。
- What actually changed: 把文稿/代码/数据资源、参照输出约束的函数和流程提示组织为标准服务，再接入对话执行层。
- Supporting evidence: C01、C02、C03；Figure 1展示体系，Figure 2和Figure 3提供特定方法应用。
- Reviewer assessment: 有明确工程整合与使用方式贡献；比“新的基础推理算法”更贴切。图1不是独立性能证据，受测仓库成功不支持任意论文可自动转换。
- Transferability: 可迁移的是可执行研究对象及输入输出契约；对机制建模仍须独立维护物理语义与领域测试。

## Innovation 2

- Author claim: 通过测试及多角色构建提高生成工具的可靠性和可复现性。
- Prior approach / comparison target: 每个问题让通用智能体直接读仓库并生成/执行代码；教程执行输出作为参照。
- What actually changed: 将环境准备、教程执行、函数参数化和失败淘汰前置，使查询复用已验证函数。
- Supporting evidence: C02、C03、C10；C09同时暴露74/100的转换边界。消融细节不在所给PDF，不能据其概述量化各模块独立贡献。
- Reviewer assessment: 基准支持整体系统在所测条件下改善执行一致性；不能独立识别标准协议、多智能体分工、预计算和提示差异各自的因果贡献。数值与图像容差仍是工程验收标准。
- Transferability: 对ODE工作流可用独立参考轨迹、质量守恒、单位和边界条件测试替换通用相似度标准；尚未验证收益。

## Innovation 3

- Author claim: 多篇论文智能体协作可以产生新分析策略和发现。
- Prior approach / comparison target: 研究者自行连接方法论文与数据论文，手工选择证据整合路径。
- What actually changed: 服务接口使模型预测、CRE干预和敲低特征易于联合查询，智能体提出候选策略后由人类选择执行。
- Supporting evidence: C04、C06；Figure 4与Extended Data Figure 2提供个案。
- Reviewer assessment: 支持跨论文计算流程和候选假说生成；签名相关是否总体新颖、本研究是否完成终局因果发现均未被这些个案证明。人的选择是方法组成部分，不能省略。
- Transferability: 可以探索机理模型、运行数据和诊断工具之间的有监督组合；不可把遗传学因果证据直接类比为污水系统机制确认。

# Limitations

1. 26/100计算生物学仓库未成功转换，缺代码/数据/模型、环境失败和不可泛化脚本限制了适用范围。不能以593/599工具通过率遮蔽上游论文转换失败。
2. 教程派生参照保证执行一致性，不能保证参照本身科学有效；主文对开放题明确提示“与单一参照一致”不等于分析有效性。
3. 专家评分未正式盲法，可能受输出形式和轨迹影响；影响大小未报告。问题难度、提示和可访问信息的差异限定系统比较。
4. 案例集中于计算/数据密集研究，TISSUE及跨论文发现主要是示例。学科外泛化须看限定语料，不能推广至没有可执行方法的所有论文。
5. 补充材料未提供限制了对消融、提示改写、更换模型、所有候选/全部数据集的独立核查。本review不把缺资料当作论文本身缺实验，也不将作者概述当作已复核结果。
6. 系统需要API、环境与长期依赖维护；公开执行接口还有权限、数据安全和归属问题。本文仅评论论文所论及的边界，没有实际部署其代码或复现其费用。

# Reproducibility

原文提供Paper2Agent代码、三个MCP服务及AlphaGenome智能体链接，Data availability列出公共数据入口；Reporting Summary列出Python和软件版本/提交。代码/数据入口的存在与当前可运行性不同，本次未克隆或执行其科学工作流。可复现性结论限于作者的执行测试报告及原PDF图表可见证据。

本review的技术可追溯性通过原PDF哈希、原始提取文件哈希和A01–A05定位实现。原PDF为18页，原始Markdown/JSON不改。发布证据包只含本review、manifest及验证记录，不含全文提取、源PDF或原图；重跑需要读者拥有同哈希的合法本地源文件。确定性验证只能检查完整性/引用/来源绑定，科学审核另行开展。

# Transferability

以下为本review者的条件性分析，不是论文实验结果。对ASM和结构化机理模型，可把状态变量、参数单位、化学计量关系、速率函数、边界条件和求解入口作为服务契约，把守恒和参考算例作为验收依据。模型资源承担可追溯出处，流程提示说明校准、诊断和情景分析的依赖顺序。不能允许自然语言层在无审计下更改机理含义。

对Hybrid ODE和Neural ODE，可探索封装数据切分、可微求解、训练和外推评估，并把随机种子、时间段及误差阈值纳入记录。验收应覆盖数值稳定性、状态约束、守恒残差、可辨识性以及分布外表现；本文没有证据证明Paper2Agent已经提高这些任务的性能。最可迁移的原则是把工具执行与证据裁决分开，而非增加不必要的智能体数量。

# Critical assessment

论文的主要价值是把可执行研究成果组织成可检查、可组合的服务，并在多个条件明确的基准中展示了较好的执行一致性。标准协议、自动测试和流程提示形成完整工程方案；当前PDF不足以独立分离每个模块的增益，也不足以确认其全部新颖性主张。

本次结论分三级：其一，工具/流程接口与受测输出复现有具体图表及主文支持；其二，跨论文组合能够生成和执行候选分析，有人类决策参与；其三，自主且可靠地产生最终科学结论没有被这些案例证明。对用户研究的迁移价值主要落在接口、追溯和领域验收设计，实际建模收益仍需独立实验。
